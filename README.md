# CyberCrowd deal playbook (DXR Cyber)

Password-gated guide: seven everyday CyberCrowd deals worked end to end in Salesforce.

Only the encrypted gate (`index.html`) is published. The plaintext guide and screenshots stay local (git-ignored).

To update: edit `build/guide.html` or the screenshots in `build/img/`, then run `./publish.sh` (it asks for the password).
